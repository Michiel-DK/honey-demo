# honey demo

**Live page:** https://michiel-dk.github.io/honey-demo/

honey was an inventory tool for restaurants that we built at [roger3000](https://roger3000.com) in 2026: it derived
stock from sales and deliveries, drafted orders, read supplier invoices, and was built to grade its own forecasts against what
later happened. Development is paused while the studio works on business automation.

This repo holds only the product story page, a single `index.html` with its images. Every restaurant, dish, supplier
and figure on it is generated demo data for a fictional burger restaurant. The product's source code is private.
